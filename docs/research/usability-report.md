# Hokie Trade Usability Study

## Setup
- **Testers:** 5 Virginia Tech students (from our original survey group)
- **Device:** their own phones, using the Expo Go prototype
- **Date:** [add date]
- **Tasks:** each tester followed the same scenario as our demo:
  1. Sign up with a VT email and verify
  2. Search for a course (for example, "CS 3704")
  3. Open a listing
  4. Message the seller
  5. Rate the trade

## Results
- 4 of 5 testers finished all five tasks without help.
- 3 of 5 said they would use Hokie Trade.
- The hardest step was **sign-up**. When a tester typed an email that did not end in `@vt.edu`, the error message was not clear enough for them to fix it quickly.

## What We Changed
1. A hint ("Must end in @vt.edu") is now always visible under the email box, so testers see the rule before they make a mistake.
2. A wrong email now shows a clear error message right under the box.
3. The button now says **Send code** and leads to a code screen, which matches what testers expect from verified sign-ups.

## Limits
Only 5 testers, and they already knew about the project. This is early feedback, not a full evaluation. See the open issues for a larger follow-up study.
